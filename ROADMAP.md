# Roadmap

The current pilot covers the Gospel of Mark in three witnesses (Greek NT, Peshitta, Clementine Vulgate). The headings below track what's shipped, what's next, and what's parked as a distinct sub-project.

## ✅ Shipped

- 676 Mark verses with word-level alignments across Greek / Peshitta / Vulgate, generated by Claude Sonnet 4.5
- Three view modes — Interlinear, Alignment Grid, Critical Apparatus
- Color-coded token variants (green = minor, red = major, gold = aligned, dashed-grey = unaligned)
- Click-to-open tooltips: Greek → Strong's + lemma + morphology (STEP TAGNT); Peshitta → triliteral root + sister roots + Hebrew / Arabic cognates (Aramaic Root Atlas)
- Shift-click variant tokens → inline apparatus popover
- Verse selector + prev / next pager + keyboard navigation (`←` `→`, `⌘K`)
- Global search (`⌘K`) across Greek, Latin (Vulgate), Syriac (Peshitta), English (WEB), and variant types
- Berean Interlinear preflight benchmark run over all of Mark → agreement rate published on `/about`
- Home page, About page with author card + ORCID iD, Related works links
- External links open in a new tab
- Mark 9 Vulgate versification drift remapped to NA28 boundaries

## 🎯 Up next

### Internationalization (i18n)
- Spanish UI translation (chrome + legend copy + apparatus labels)
- Chinese UI translation (Simplified + Traditional)
- Verse translations: attach WEB-equivalent Spanish + Chinese verses as a fourth display column or a click-to-show per-token translation
- Language switcher in the top bar

### Syriac font selection
- User-selectable Syriac typeface: Noto Sans Syriac (current default), Estrangelo Edessa, Serto (Jacobite), East Syriac (Nestorian)
- Per-user preference stored in `localStorage`
- Clear sample-glyph previews in the picker

### Settings in the top bar
- Promote the theme toggle, language switch, Syriac-font chooser, and rail-show/hide into a proper **Settings** icon (cog glyph) in the top bar
- Keyboard shortcut to open settings
- All tweaks persisted across sessions

## 🛠 Later

- **Expand scope to all four gospels** — Matthew / Luke / John. Corpus + alignment generation ready to scale (~$25, ~45 min batch).
- **Fourth witness: English (WEB) as a first-class column**, with alignments regenerated across four traditions
- **Additional traditions** in the Chen-scope spirit: Slavonic 1751, Coptic, Armenian, Classical Chinese (1864 固里 / 1910 英诺肯提乙)
- **Accessibility audit** — full-pass aria, keyboard-only navigation, high-contrast / dark mode polish
- **Cross-references** in variant notes ("cf. Matt 24:15") with clickable jumps between parallel verses

## 🧪 Sub-project 2 — Machine Annotation Engine

Live, on-demand alignment for verses the pilot doesn't cover. User types a reference, Claude returns a fresh alignment with confidence score. Scholar-facing: intended as a reviewable draft, not authoritative.

## 🧪 Sub-project 3 — Scholar Review Workflow

- User accounts with roles (student · scholar · editor)
- Review queue for Sub-project 2 machine proposals
- Consensus threshold (X approvals by qualified reviewers) → **published gold standard**
- Gold-standard export: TEI XML, BibTeX, CSV

## Parked

- In-viewer alignment editing by end-users (handled by Sub-project 3 instead)
- Authenticated API
- Full-text search across traditions beyond Mark
- Manuscript-variant overlay (Byz vs. NA28 vs. TR within a single witness)

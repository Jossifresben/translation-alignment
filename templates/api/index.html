Polyglot Concordance — API v1

Read-only JSON endpoints exposing the alignment data, search index, and corpus manifest. CC BY 4.0 (derived data).

Endpoints

  • /api/v1/manifest — corpus metadata, witnesses, schema
  • /api/v1/alignment/{book}/{chapter}/{verse} — canonical alignment JSON
  • /api/v1/verse/{book}/{chapter}/{verse} — display-shape verse dict
  • /api/v1/search?q={query}&limit={n} — verse-level search
  • /api/v1/openapi.json — OpenAPI 3.0 spec
  • /api/docs — Swagger UI

Quick start

curl -s https://polyglotconcordance.com/api/v1/alignment/mark/13/14 | jq .

Conventions

  • Versioning: all endpoints are under /api/v1/; payloads include api_version: "v1".
  • CORS: Access-Control-Allow-Origin: * on every response — read-only public data.
  • Caching: Cache-Control: public, max-age=86400 on stable endpoints; max-age=300 on /search.
  • Errors: { "error": { "code": "...", "message": "..." } } with appropriate HTTP status.
